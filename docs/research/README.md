# Research cache publication note

Files under this directory are research working materials, provenance records, generated metrics, and source audit intermediates. They are not the public-facing website text and should not be treated as a republication license for upstream material.

The `.gitignore` file excludes raw source caches and large intermediates such as `docs/research/**/raw/` and `docs/research/**/cache/`. If this repository is made public, confirm those ignored paths are not committed or deployed. Any file containing source excerpts, dictionary text, API responses, OCR text, snippets, or publisher metadata should remain a citation aid unless the source rights allow publication.

Public pages should prefer source URLs, short rights-compatible excerpts, public-domain material where verified, Creative Commons material with attribution, or original paraphrase.
