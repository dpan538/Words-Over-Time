# Screenshot capture notes

Store approved static captures here after the study materials are reviewed.

Recommended naming:

- `data_baseline_desktop.png`
- `data_evidence_grid_desktop.png`
- `artificial_baseline_desktop.png`
- `artificial_evidence_grid_desktop.png`
- `forever_baseline_desktop.png`
- `forever_evidence_grid_desktop.png`

Record every screenshot in `../stimuli_manifest.csv`.

Minimum manifest fields:

- source page
- capture date
- viewport size
- commit hash
- included evidence columns
- known limitations

Do not capture or store participant responses in this folder.
