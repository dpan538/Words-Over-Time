# Words Over Time visual communication package

This package reframes the Words Over Time article as visual communication and information design analysis rather than a reader study.

Working title:
From Frequency Curves to Source-Boundary Grids: Visual Communication of Semantic Change in Words Over Time

Core claim:
Words Over Time proposes a visual communication framework for representing semantic change without collapsing heterogeneous evidence into a single frequency curve.

This package supports a design research article that analyzes the interface as a visual evidence system. It does not claim to measure reader comprehension or interface effectiveness.

## Article type

Research article / design case study / comparative visual artifact analysis.

## Main materials

- `artifact_inventory.csv`: objects to analyze.
- `interface_component_map.csv`: page components mapped to visual-evidence functions.
- `evidence_column_dictionary.csv`: definitions for Signal, Attestation, Variant, Context, Boundary, and Rights.
- `claim_boundary_matrix.csv`: what each visual element allows and does not allow readers to infer.
- `comparative_interface_table.csv`: comparison with frequency curves, dictionaries, corpus search, and timeline infographics.
- `case_walkthrough_data.md`: case analysis for `data`.
- `case_walkthrough_artificial.md`: case analysis for `artificial`.
- `case_walkthrough_hub_or_privacy.md`: primary walkthrough for `hub`, with `privacy` as an optional substitute.
- `figure_inventory.csv`: proposed article figures.
- `screenshot_manifest.csv`: screenshot capture plan.
- `rights_and_source_boundary_notes.md`: source and rights framing for the article.

## Claim discipline

Use:

- "encodes evidence boundaries"
- "separates heterogeneous evidence types"
- "visually constrains over-inference"
- "makes source boundaries available for inspection"
- "treats uncertainty as part of the interface"

Avoid:

- "proves readers understand semantic change better"
- "improves comprehension"
- "reduces misinterpretation"
- "validates the interface"

Those stronger effectiveness claims would require a reader study.
