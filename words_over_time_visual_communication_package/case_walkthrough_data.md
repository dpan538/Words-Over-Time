# Case walkthrough: data

## Article role

`data` is the clearest case for showing how a word moves from evidence and counted things into infrastructure, platform traces, governance pressure, and grammatical instability.

Use this case to argue that semantic change cannot be responsibly visualized by a frequency curve alone. The page uses multiple visual grammars because `data` carries multiple evidence problems at once.

## Visual sequence

The page presents four movements:

1. Historical index: a long formation view that keeps recent density from swallowing older evidence.
2. Socialized data generation: platform-era zones where data becomes trace, profile, resource, risk, and governed object.
3. Datum route: a grammatical path from singular item to mass infrastructure.
4. Cross pressures: a field of simultaneous claims around personal attachment, institutional restriction, scientific evidence, and ethical responsibility.

## Source-boundary analysis

The historical index is a Signal component. It can show visibility and period pressure, but it cannot prove total cultural importance.

The socialized generation chart is a Context component. It connects platform-era phrases and zones, but it does not claim that AI alone produced social data.

The datum route is a Variant component. It makes grammatical policy visible: `datum`, `data are`, and `data is` are not treated as interchangeable labels.

The cross-pressure field is a Boundary component. It refuses to resolve modern data into one domain and instead visualizes incompatible claims as co-present.

## Claim discipline

Use:

> The `data` page demonstrates how an interface can distribute semantic change across signal, context, variant policy, and claim boundary.

Avoid:

> The `data` page proves that readers understand data's semantic history more accurately.
