# Prompt Recipes

Use this reference when a user needs examples for invoking the skill or when publishing the skill for other people to try.

## Design From Research Notes

Prompt:

```text
Use $infographic-editorial-design to turn these research notes into a source-led editorial infographic. Define the claim, evidence layers, page sequence, visual system, caveats, and verification checklist.
```

Expected output:

- Concept statement.
- Evidence contract.
- Section-by-section page spine.
- Visual rules for grid, typography, color, data marks, and interaction.
- Claim boundaries and rights notes.

## Redesign A Data Page

Prompt:

```text
Use $infographic-editorial-design to critique and redesign this data page. Keep the content, but improve hierarchy, evidence traceability, source labels, and responsive behavior.
```

Expected output:

- Findings ordered by severity.
- Revised information architecture.
- Concrete visual and content changes.
- Responsive and accessibility checks.

## Build A Web Poster

Prompt:

```text
Use $infographic-editorial-design to implement a web-based research poster for this dataset. Use the local design system and create an auditable chart sequence with source and method notes.
```

Expected behavior:

- Inspect existing components and styles first.
- Reuse local typography, spacing, color tokens, and data utilities.
- Implement the artifact, then verify layout, text fit, and evidence labels.

## Create A Static Editorial Poster

Prompt:

```text
Use $infographic-editorial-design to design a static editorial poster explaining this archive. Make the data hierarchy, uncertainty, and source rights visible.
```

Expected output:

- Poster grid.
- Title and metadata hierarchy.
- Visual modules.
- Source ledger.
- Caveat placement.
- Export/checklist notes.

## Review Before Publication

Prompt:

```text
Use $infographic-editorial-design to review this infographic before publication. Focus on whether the design overclaims, hides uncertainty, confuses source types, or weakens the reading path.
```

Expected output:

- Critical issues first.
- Exact places where the design implies more than the sources support.
- Fixes that preserve the user's visual direction where possible.
- Residual risks.

## Adapt An Editorial Design Method

Prompt:

```text
Use $infographic-editorial-design to adapt a rigorous editorial design method for a different subject without copying any existing project's visual identity. Keep the evidence discipline and editorial structure, but propose a new palette and module language.
```

Expected output:

- Which principles transfer.
- Which project-specific elements should not be copied.
- New visual programme.
- Attribution language.
