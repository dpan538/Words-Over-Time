# Grid System

Use this reference when choosing or critiquing the structural grid behind an infographic, editorial data story, research poster, dashboard, or visual essay.

A grid is not decoration. It is the reading contract between evidence, sequence, comparison, and hierarchy.

## Grid Decision

Before drawing, answer:

1. What must be compared?
2. What must be read in sequence?
3. What must remain visibly separate?
4. What evidence is missing, uncertain, or restricted?
5. What changes by viewport, format, or publication medium?

Choose the grid after these answers, not before.

## Core Grid Types

### Manuscript Grid

Use for essays, methods notes, long interpretation, and source explanations.

- One main text block.
- Strong margins.
- Clear headline, body, caption, and note hierarchy.
- Best when argument and reading continuity matter more than many simultaneous comparisons.

### Column Grid

Use for editorial pages, source ledgers, multi-part explanations, and mixed text/chart layouts.

- Two to six columns.
- One column can hold metadata, labels, or section navigation.
- Main columns hold charts, body text, and evidence modules.
- Best for keeping source, claim, and visualization aligned.

### Modular Grid

Use for dense evidence systems, repeated records, dashboards, small multiples, and archive maps.

- Columns and rows form reusable cells.
- Missing cells can mean absent or pending evidence.
- Modules should share dimensions unless the data requires hierarchy.
- Best when the artifact must compare many records or categories.

### Baseline Grid

Use when typographic rhythm is central.

- Align body text, captions, labels, and table rows to a shared vertical rhythm.
- Works especially well for editorial, museum, catalog, and report-like artifacts.
- Use to make dense information feel intentional rather than cluttered.

### Timeline Grid

Use when temporal reading is primary.

- Horizontal time axis for long-range comparison.
- Vertical lanes for source type, semantic branch, geography, institution, or confidence.
- Break, compress, or inset time only when the transform is labeled.
- Best for showing change without turning sequence into causation.

### Map Or Spatial Grid

Use when geography, territory, architecture, interface space, or network space matters.

- Pair spatial position with legends, scale, projection notes, and source caveats.
- Do not imply geographic causation without evidence.
- Use inset maps or small multiples when one map becomes overloaded.

### Constellation Or Network Grid

Use when relation is more important than linear sequence.

- Nodes and links must have explicit meanings.
- Use spatial clusters cautiously; readers will infer hierarchy or causality.
- Provide an inspector, legend, or adjacency table for proof.
- Best for semantic fields, institutional relations, dependency maps, and conceptual neighborhoods.

## Evidence-Lane Grid

For source-led editorial infographics, a strong default is an evidence-lane grid:

- Signal
- Attestation
- Variant
- Context
- Boundary
- Rights

These lanes can become columns, rows, tabs, legends, or inspector fields. The important move is separation: evidence, interpretation, caveat, and rights should not collapse into one undifferentiated visual layer.

## Grid As Argument

Use the grid to express:

- Commensurability: records share a comparable structure.
- Sequence: the reader moves through time, method, or argument.
- Boundary: source families and claim types remain separate.
- Absence: missing evidence is shown as a gap, faded cell, empty lane, or dashed state.
- Scale: main claim, supporting evidence, and caveat have different weights.

If the grid cannot explain why elements sit where they sit, the design is not yet structured.

## Responsive Grid Rules

- Preserve evidence structure before preserving decorative symmetry.
- Stack columns only when labels and source boundaries remain clear.
- Use horizontal scroll for dense comparative structures rather than shrinking text below readable size.
- Convert side metadata into stacked rows on mobile.
- Move dense detail into inspectors when mobile space cannot support all labels.
- Keep reading order explicit after reflow.

## Grid QA

Before finishing:

- Can a reader identify the primary reading direction?
- Can a reader tell which items are comparable?
- Are missing, pending, or restricted evidence states visible?
- Are source labels and caveats attached to the right module?
- Does the mobile version preserve the same argument?
- Does the grid still work without color?
